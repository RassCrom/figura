Silent placeholder files for the MVP sound system.

- `menu-ambient.mp3`: menu loop.
- `round-tension.mp3`: active round loop.
- `reveal-flourish.mp3`: reveal transition cue.
- `tick.mp3`: countdown tick.
- `wrong.mp3`: wrong guess cue.
- `correct.mp3`: correct guess cue.

The current hook uses Web Audio synthesis so the empty files can be replaced later without changing call sites.
